# rituraj.tech ✦ Personal Portfolio & Engineering Archive

> Editorial developer portfolio, systems showcase, and academic dashboard of **Ritu Raj** (M.Tech CSE @ IIT Patna, B.Tech CSE @ Techno India University).

Visit live: [rituraj.tech](https://rituraj.tech)

---

## ⚡ Features & Highlights

- **Kinetic Exhibition Hero**: Custom typography pairing Mazius Display serif with Neue Montreal & JetBrains Mono, magnetic interactions, and smooth momentum scrolling powered by Lenis & GSAP.
- **Editorial Works Exhibition**: Asymmetric project cards with interactive live screenshot filmstrip switchers, tech stack chips, and an interactive Project Lightbox Gallery modal.
- **IIT Patna Academic Dashboard**: Secure terminal-inspired study suite featuring real-time M.Tech schedule tracking, lecture notes repository, algorithmic roadmap with progress meters, and smart task management.
- **Dynamic Experience & Education**: Interactive chronology covering academic journey at IIT Patna & Techno India University alongside leadership and development roles.
- **Production Performance**: Zero-dependency bloat, lightning-fast Vite compilation, responsive touch support, and full keyboard accessibility.

---

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, HTML5
- **Styling**: Vanilla CSS (Custom Design System with editorial tokens & typography)
- **Animation & Motion**: GSAP, ScrollTrigger, Lenis Smooth Scroll
- **Icons**: Lucide React
- **Build Tool**: Vite 6

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/imrituraj/rituraj.tech.git

# Navigate into the project root
cd rituraj.tech

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be available at `http://localhost:5173/`.

### Production Build

```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview production bundle locally
npm run preview
```
